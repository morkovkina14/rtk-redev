## Инструкция по запуску:

1. Установка зависимостей: `npm install`
2. Запуск сервера разработки: `npm run dev`

Reconciliation- это внутренний процесс сравнения состояния компонента (старое и измененное) с помощь Virtual DOM, при котором совершается минимальное количество изменений.

Key- это уникальный паспорт, благодаря которому реакт четко понимает, что и с каким элементом нужно совершить действие.

Если использовать ключ- index это приведет к багам. В том же примере с ключом и инпутом, при написании текста в первом инпуте и при удалении этой же ячейки, инпут оставался на месте. Внутри JS удаляла первый элемент, но реакт с целью оптимизации не двигал верстку,а зачищал последнюю ячейку и все данные вновь переписывал по индексам. Поэтому инпут прилипал к ячейке, где совпадал индекс(а вот если прописать инпут в последней ячейке и удалить любую ячейку, то инпут пропадет).

Реакт с id работает четко с нужным элементом. С key это постоянная перерисовка под index (он всегда остается на месте, строго с 0).
